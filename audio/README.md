# English pronunciation clips

These 24 clips were generated locally for this application using the FFmpeg
`flite` filter, the Carnegie Mellon Flite `slt` US English voice, a playback
tempo of 0.9, and mono 24 kHz MP3 output. No remote speech service is used.

Source vocabulary: `src/game.ts`.
Regeneration script: `scripts/generate_audio.py`.

Flite: https://www.festvox.org/flite/

The synthesis library is not included in the web application. See
`FLITE-LICENSE.txt` for its attribution and permissive license notice.
